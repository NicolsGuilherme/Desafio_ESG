Infraestrutura como Código

Estratégia de Containerização Docker

Boas práticas para alta performance, baixo consumo e máxima segurança.

📦 Multi-Stage Build Otimizado
• Build Stage: Maven 3.9 + JDK 21 Alpine.
• Runtime Stage: JRE 21 Alpine mínima (~180MB).
• Isolamento completo de compiladores no artefato final.
🛡️ Hardening & Segurança
• Usuário não-root: appuser:appgroup.
• Process Manager dumb-init para graceful shutdown.
• Healthcheck nativo via endpoint /actuator/health.
⚙️ Ajuste de JVM para Containers
JAVA_OPTS="-XX:+UseContainerSupport -XX:MaxRAMPercentage=75.0 -XX:+ExitOnOutOfMemoryError"
Garante que o Spring Boot respeite estritamente os limites de cgroups do Docker e Kubernetes sem estourar a memória do host.
